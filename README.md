# NOVA AUTO — Premium Car Care & Detailing Studio

Демонстрационный лендинг премиальной детейлинг-студии от **NOVA lab**.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Стек

React 19 · Vite · Framer Motion (анимации) · Lenis (плавный скролл) · чистый CSS с дизайн-токенами.

## Структура

- `src/data/content.js` — все тексты, услуги, цены, отзывы и контакты в одном месте
- `public/images/` — фотографии в WebP (640/1080/1600 px), `src/lib/images.js` — их список и `srcset`
- `src/components/` — секции лендинга, `src/components/ui/` — общие компоненты

## Что демонстрационное

- Форма записи валидирует данные, но никуда их не отправляет
- Отзывы, цены, адрес и телефон — условные данные
- Схема проезда — стилизованная иллюстрация вместо карты
- Слайдер «до/после» — визуализация эффекта на одном фото, не реальный кейс
- Соцсети — без ссылок

## Для запуска реального бизнеса

1. Подключить отправку заявок (Telegram-бот, почта или CRM) в `src/components/Booking.jsx`
2. Встроить Яндекс.Карты в `src/components/Contacts.jsx`
3. Заменить фото (сейчас — бесплатные снимки Unsplash) на собственные съёмки студии и работ
4. Обновить контакты, цены, отзывы и ссылки на соцсети в `src/data/content.js`
5. Добавить политику обработки персональных данных (152-ФЗ) и ссылку на неё у согласия в форме
6. Настроить домен, хостинг, аналитику (Яндекс Метрика) и разметку Schema.org
