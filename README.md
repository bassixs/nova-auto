# DARK VISION — автомойка и детейлинг в Калуге

Сайт DARK VISION: каталог услуг с ценами по категориям автомобилей, две локации и онлайн-заявка на запись.

Демонстрационная версия NOVA AUTO, из которой вырос сайт, сохранена в теге `nova-auto-demo`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Стек

React 19 · Vite · Framer Motion · Lenis · JS API Яндекс Карт · чистый CSS с дизайн-токенами.

## Где что менять

| Что | Файл |
| --- | --- |
| Телефон, адреса, график, соцсети, рейтинг, реквизиты для политики | `src/data/business.js` |
| Услуги и цены (единственное место, где записан прайс) | `src/data/services.js` |
| Тексты секций и подбор фотографий | `src/data/content.js` |
| Мета-теги и Schema.org | собираются из `business.js` в `vite.config.js` |
| Политика обработки персональных данных | `privacy.html` |
| Обработчик заявок | `server/booking-function/` |

### Цены

Каждая услуга в `services.js` хранит цены для категорий №1–№4. `fix(1000)` — точная цена, `from(1500)` —
цена «от»: пометка выводится на сайте автоматически везде, где показана эта цена.

### Фотографии

Файлы лежат в `public/images` в трёх размерах: `<имя>-640.webp`, `<имя>-1080.webp`, `<имя>-1600.webp`.

- Фото локации: положите три файла и укажите имя в поле `photo` нужной локации в `business.js`
  (например, `photo: 'location-guryanova'`). Пока фото нет, карточка показывает номер локации.
- Галерея: добавьте запись в `GALLERY` в `content.js`.

Сейчас в галерее и карточках направлений стоят декоративные фотографии с Unsplash. Это не работы студии,
поэтому они нигде не подписаны как результат DARK VISION.

## Настройки сборки

Задаются переменными (см. `.env.example`), на GitHub — в **Settings → Secrets and variables → Actions → Variables**:

- `VITE_BOOKING_ENDPOINT` — адрес обработчика заявок. Подключение: [docs/booking-setup.md](docs/booking-setup.md).
- `VITE_YM_ID` — номер счётчика Яндекс Метрики. Цель `booking_sent` срабатывает при успешной отправке заявки.
- `VITE_YMAPS_KEY` — ключ JS API Яндекс Карт (необязателен).

## Публикация

Пуш в ветку `main` запускает сборку и публикацию на GitHub Pages
([.github/workflows/deploy.yml](.github/workflows/deploy.yml)). Источник Pages в настройках репозитория —
**GitHub Actions**.

При переезде на свой домен поменяйте `SITE.url` в `src/data/business.js` и `ALLOWED_ORIGINS` у обработчика заявок.

## Перед запуском в работу

1. Подтвердить у заказчика телефон, график и соцсети (сейчас взяты из карточек Яндекс Карт).
2. Добавить реальные фотографии обеих локаций и работ.
3. Подключить приём заявок ([docs/booking-setup.md](docs/booking-setup.md)).
4. Заполнить реквизиты оператора в `LEGAL` (`business.js`), согласовать `privacy.html` с юристом
   и поставить `approved: true`.
5. При подключении Метрики добавить уведомление об использовании cookie.
