# Подключение приёма заявок

Сайт размещён на GitHub Pages и не имеет своего сервера, поэтому заявку принимает небольшой внешний
обработчик. Он проверяет данные, отсекает спам и пересылает заявку в Telegram администратору.

```
Форма на сайте  →  обработчик (server/booking-function)  →  Telegram-чат администратора
```

Токен бота хранится только в настройках обработчика. В коде сайта и в браузере посетителя его нет.

Пока обработчик не подключён, сайт честно предупреждает об этом под кнопкой отправки и никогда не показывает
«Заявка отправлена»: посетителю предлагают записаться по телефону.

## Шаг 1. Создать Telegram-бота

1. В Telegram открыть [@BotFather](https://t.me/BotFather), отправить `/newbot`, задать имя и логин бота.
2. Сохранить выданный токен вида `1234567890:AA...`. Никому его не передавать и не публиковать.
3. Создать группу для заявок (или использовать личный чат), добавить в неё бота и написать любое сообщение.
4. Узнать id чата: открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти `"chat":{"id":...}`.
   У групп id отрицательный, например `-1001234567890`.

## Шаг 2. Развернуть обработчик

Рекомендуемый вариант — **Yandex Cloud Functions**: сервис работает в России, поэтому посетители достучатся до
него с любого оператора, а бесплатного лимита с запасом хватает на заявки автомойки.

1. Зайти в [консоль Yandex Cloud](https://console.yandex.cloud), создать платёжный аккаунт и каталог.
2. **Cloud Functions → Создать функцию**, имя — например `dark-vision-booking`.
3. Среда выполнения — **Node.js 18** или новее. В редакторе создать файл `index.js` и вставить в него содержимое
   [`server/booking-function/index.js`](../server/booking-function/index.js).
4. Точка входа: `index.handler`. Таймаут: 10 секунд. Память: 128 МБ.
5. Переменные окружения:

   | Переменная | Значение |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
   | `TELEGRAM_CHAT_ID` | id чата из шага 1 |
   | `ALLOWED_ORIGINS` | `https://bassixs.github.io` (при переезде на свой домен — добавить его через запятую) |

6. Сохранить версию, затем на странице функции включить **Публичную функцию**.
7. Скопировать **ссылку для вызова** вида `https://functions.yandexcloud.net/d4e...`.

Обработчик не привязан к Yandex Cloud: функция `handleBooking` в том же файле принимает метод, адрес сайта и
тело запроса и возвращает ответ, поэтому её можно обернуть для любого другого хостинга с Node.js.

## Шаг 3. Сообщить сайту адрес обработчика

Адрес обработчика не секретный, он задаётся при сборке:

1. В репозитории на GitHub: **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**.
2. Имя `VITE_BOOKING_ENDPOINT`, значение — ссылка из шага 2.
3. **Actions → Deploy to GitHub Pages → Run workflow**, чтобы пересобрать сайт.

Для локальной проверки создайте файл `.env.local` в корне проекта:

```
VITE_BOOKING_ENDPOINT=https://functions.yandexcloud.net/d4e...
```

## Шаг 4. Проверить

1. Открыть сайт, собрать заявку и отправить её.
2. В Telegram-чате должно появиться сообщение «Новая заявка с сайта DARK VISION».
3. На сайте — экран «Заявка отправлена». Предупреждение под кнопкой отправки должно исчезнуть.

Проверить обработчик без Telegram можно локально:

```bash
DRY_RUN=1 ALLOWED_ORIGINS=http://localhost:5173 node server/booking-function/index.js
```

Заявки будут печататься в консоль. В `.env.local` при этом укажите `VITE_BOOKING_ENDPOINT=http://localhost:8787`.

## Защита от спама

- Скрытое поле-ловушка: люди его не видят, боты заполняют. Такие заявки молча отбрасываются.
- Заявка, отправленная быстрее чем за 2,5 секунды после открытия формы, считается автоматической.
- Не больше 5 заявок за 10 минут с одного IP-адреса.
- Заявки принимаются только с адресов из `ALLOWED_ORIGINS`.
- Длина всех полей ограничена, телефон проверяется.

Если спам всё же появится, следующим шагом стоит добавить Yandex SmartCaptcha.

## Что учесть

- Telegram — зарубежный сервис. Если юрист заказчика считает пересылку имени и телефона туда нежелательной,
  замените функцию `sendToTelegram` на отправку письма или запись в CRM: остальной код менять не нужно.
- Способ доставки заявок нужно указать в политике обработки персональных данных (`privacy.html`, раздел 6).
